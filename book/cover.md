# Gut Feelings

First Principles of a Software Crafter

![A gut feeling in the real world](./book/media/cover.png)

Gut Feelings: First Principles of a Software Crafter is written by Markus Tacker[^homepage], an software crafter with three decades experience writing web application software. This book aims to put the gut feelings he uses when writing software into words so they can be tought to others.
